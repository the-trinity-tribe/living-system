# Living System 0.2.0 preview 1

Released 2026-10-24. **A preview for testing and feedback.** The final 0.2.0 follows after a round of hands-on testing.

## In one sentence

Version 0.1 showed how people and AI agents can share rules that only people approve. Version 0.2 turns that into a workspace you can install, grow and use every day, alone or as a team.

## What's new

**Set up in minutes.** Your own private workspace in a separate folder, guided by your agent in a few questions. Profiles for students, professionals, employees and managers; starter files in English, German and Polish.

**Your rules stay yours.**
- Agents propose; your review creates, replaces or retires a rule.
- A write guard stops agents from editing rules, approving things for you, or writing passwords into files.
- A review record shows if an approved rule was changed afterwards.
- E-mails and documents from others are treated as information, never as instructions, and scanned for hidden ones.

**Every day.** See what needs you (`status`), catch up after time away, park an idea without switching task, tidy up one item at a time, and switch on focus mode when you need quiet.

**Learning, not just doing.** The agent explains its choices, can coach you so your own skills stay sharp, quizzes you on your own rules, and prints a handbook for working without any AI.

**Teams.** A shared company workspace plus private personal ones. People hand on what they learned in a role, without personal data. Newcomers get a gradual onboarding path. Nobody approves their own change.

**Repeated work.** A counter suggests automation only after the third time. There are ten optional modules: weekly update, meeting notes, lessons, knowledge inbox, second check, careful run, work audit, research review, client intake and content preparation.

**Upkeep.** A health check (`doctor`), safe upgrades that never overwrite your edits, and one-file backups you can verify.

**Showing value.** A 10-minute value check you run yourself, and a counts-only evidence summary for making the case honestly.

The full list is in [CHANGELOG.md](../../CHANGELOG.md).

## Try it

```sh
git clone https://github.com/the-trinity-tribe/living-system.git
cd living-system
python3 tools/living.py
```

Then follow the [testing guide](../../TESTING.md) (30 minutes), or open the folder in Claude Code or Codex and say *"Read INSTALL.md and set up my workspace."* On Windows, type `py` instead of `python3`.

**Coming from 0.1?** 0.1 had no installable workspace; the example organisation moved to `demo/moss-and-circuit/`. Create a new workspace with `init`.

## Known limitations

- Experimental. Not a security boundary: no login, and names in approvals are labels, not proof of identity.
- Agent behaviour (skills, coaching, onboarding, focus) is guided by instructions and tested in recorded sessions, not by the automatic tests.
- The write guard works in Claude Code, and in Codex once you trust its hooks.
- German and Polish starter texts need a native-speaker review.
- Nothing measures time, money or energy saved, and the docs make no such claims.

## Quality

- Over 350 automated tests run on Linux, Windows and macOS with Python 3.10 and 3.13.
- Six independent code reviews found 124 defects; all were fixed, each with a test.
- A release check keeps personal paths, e-mail addresses and secrets out of the repository.
