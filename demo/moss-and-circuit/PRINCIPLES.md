# PRINCIPLES.md

The principles this system runs on now. Nothing here is aspirational.

1. **Human authority.** AI can reason and propose. Humans decide canonical organisational state.
2. **Smallest sufficient context.** Load what the task needs, not everything available.
3. **Explicit uncertainty.** Unknown, disputed and inferred information stays visibly different from approved information.
4. **Local-first, vendor-independent ownership.** The durable system is plain, human-readable files that do not depend on any one AI provider.
5. **Observable system state.** A human can see the current state of the system and where each important rule comes from.
6. **Third-Run Rule.** Do not automate recurring work before observing enough real manual runs to understand what is actually being automated.
