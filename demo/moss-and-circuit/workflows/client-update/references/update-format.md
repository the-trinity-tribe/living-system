# Update format (reference)

Invented for this demo. Not a canonical rule.

An update to the garden has four short parts:

1. **Greeting**: one line.
2. **What changed**: bullet list, one fact per bullet.
3. **What we need from you**: one clear question or "nothing needed".
4. **Sign-off**: the name of the person who approved it.

Rules of style:

- Plain words, under 150 words.
- Dates written in full (for example "Saturday 31 October").
- No pricing, no new promises, no opinions about other parties.
- Anything not recorded in the project file stays out of the update.
