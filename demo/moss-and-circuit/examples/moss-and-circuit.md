# About the Moss & Circuit example

**All organisations and people here are fictional.**

**This file is explanation only, not an authoritative source.** If it ever disagrees with `SYSTEM.md` or `decisions/`, those win.

Moss & Circuit exists to give this repository realistic but small work to run on. It is a three-person studio working with neighbourhood groups, currently on one project with a community garden.

The example is deliberately small. It has enough people, rules and project state to test whether an agent finds the right source, and not so much that an agent needs to read everything.

For facts about the organisation, read `SYSTEM.md`. For the current project, read `projects/`.
