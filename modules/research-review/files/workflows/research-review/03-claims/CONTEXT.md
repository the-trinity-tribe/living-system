# Stage 3: check claims against sources

## Inputs

| Source | File | Scope | Why |
| --- | --- | --- | --- |
| Sources | newest file in `../02-sources/output/` | All | The evidence |

## Process

1. List each claim that answers the question.
2. For each: the source and the place in it, and how strong it is (one source, several, conflicting).
3. List conflicting evidence next to the claim it conflicts with.

## Outputs

`output/<date>-claims.md`

## Checkpoint

Every claim has a source or is marked 'not found'.
