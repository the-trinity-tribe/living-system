# Stage 3: make

Do the planned steps, inside scope.

## Inputs

| Source | File | Scope | Why |
| --- | --- | --- | --- |
| Card | `../runs/<card>` | Plan, Scope | What to do |
| Checker list | newest file in `../04-check/output/` | If any | What to fix |

## Process

1. Do the steps in order. Note anything surprising under Notes.
2. If a step needs something outside scope, stop and ask; record a yes under Scope changes.
3. To pause, record a checkpoint (see `../CONTEXT.md`).
4. When done, set `Stage: 3-make done`.

## Outputs

The changed files; notes in the card

## Checkpoint

Done, or paused with a checkpoint.
