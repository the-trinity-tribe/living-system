# Profiles: extra checks per kind of work

Use the section that matches the run card's profile, in plan, check and verify.

## Code

- Tests exist for the change and pass; no unrelated files changed.
- Secrets, keys and personal data are not in the diff.
- How to roll back is one command or one revert.

## Website

- Links work, pages load on a phone-width screen, images have text alternatives.
- Nothing is published before hand back.

## Content

- Facts have sources; numbers are measured, not guessed.
- Tone fits the audience; the human publishes.

## Research

- Every claim points to a source with a date; open gaps are listed, not filled in.

## Operations

- Each step is reversible or has a written way back; the order of steps is safe if interrupted.

## General

- The result matches "Done when"; nothing outside scope changed.
