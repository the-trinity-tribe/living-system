# Stage 1: frame

Write down what is wanted before any work starts.

## Inputs

| Source | File | Scope | Why |
| --- | --- | --- | --- |
| Human | Their request | All | What is asked |
| Template | `../references/run-card.md` | All | The card |

## Process

1. Copy the template to `../runs/<date>-<name>.md`.
2. Fill in Goal, Profile, Done when, Scope and Risk with the human, one question at a time.
3. Mark Risk high if anything in the risk list in `../CONTEXT.md` applies.
4. Set `Stage: 1-frame` and show the card.

## Outputs

The card in `../runs/`

## Checkpoint

The human confirms the card.
