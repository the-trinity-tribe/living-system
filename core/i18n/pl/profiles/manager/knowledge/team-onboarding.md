# Wdrożenie nowej osoby do zespołu

Tło, niewiążące. Użyj tego, żeby wprowadzić nową osobę do przestrzeni roboczej.

1. Przekaż jej zatwierdzone decyzje, które jej dotyczą (`python3 tools/review.py current` je wypisuje).
2. Wyjaśnij, że agent proponuje, a decydują ludzie z prawem do zatwierdzania.
3. Pokaż jej `proposals/`, żeby zobaczyła, jak proponuje się zmianę.
4. Poproś ją, żeby przeczytała `SYSTEM.md` i powiedziała, co jest błędne lub czego brakuje. Błędy i braki stają się propozycjami, a nie cichymi poprawkami.
5. Ustalcie, gdzie są notatki prywatne. Notatki prywatne zostają poza tą wspólną przestrzenią roboczą.
