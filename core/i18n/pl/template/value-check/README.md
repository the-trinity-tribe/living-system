# Test użyteczności

Mały test, czy ten system naprawdę ci pomaga. Robisz go ty, nie agent.

1. **Zanim** zaczniesz polegać na systemie: zapisz 5 pytań o swoją pracę, na które znasz już prawdziwą odpowiedź (na przykład „Kto musi zatwierdzić X?”). Wpisz je do `questions.md`.
2. Zadaj każde pytanie nowej sesji AI. Nie podpowiadaj.
3. Przy każdej odpowiedzi wpisz jedno słowo w kolumnie **Przed**: `dobrze`, `źle`, `zmyślone` (brzmiało pewnie, ale było wymyślone) albo `nie wiem` (przyznała, że nie zna odpowiedzi).
4. Po kilku tygodniach korzystania z systemu zadaj te same pytania w nowej sesji i wypełnij kolumnę **Po**.
5. Policz wyniki: `python3 <folder Living System>/tools/living.py value-score .` (uruchom w tej przestrzeni roboczej; narzędzie jest w folderze Living System, z którego instalowałaś lub instalowałeś). Możesz też poprosić o to agenta.

W `log.md` zapisz, co zauważyłaś lub zauważyłeś. Odpowiedź „zmyślona” jest najważniejsza do obserwowania: właśnie temu ten system ma zapobiegać.

To twój własny, nieformalny test, a nie pomiar naukowy.
