# Przekazanie: najnowsze

Niewiążące. Ta notatka pomaga następnej sesji zacząć tam, gdzie skończyła się poprzednia. Nigdy nie stoi wyżej niż zatwierdzone pliki.

Żadna sesja nie została jeszcze przekazana.

Na koniec sesji agent zastępuje ten tekst następującymi punktami:

- **Data i nad czym pracowaliśmy**
- **Co zostało zrobione** (z odwołaniem do plików)
- **Co jest jeszcze otwarte**
- **Propozycje czekające na twój przegląd** (nazwy plików)
- **Jeden następny krok dla ciebie**
